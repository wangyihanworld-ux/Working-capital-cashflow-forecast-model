# 控制情景与现金口径

运行 `python -m working_capital.comparison`。`docs/evidence/controlled_cash_comparison.csv` 比较基准、仅周转、仅OPEX、共同改善和回款库存联合压力。保持收入增长与COGS率相同；分解表单列交互项。基准DSO/DIO/DPO为48/60/40，改善40/48/48，OPEX率34%到32.5%。

最低现金要求为75百万元的模拟输入。最低余额、最大缺口、缺口月份数及最长连续月份只基于12个月末，不能识别月内峰值。压力情景是同时增加DSO和DIO的假设，不是独立随机风险。未建模税费、资本支出、债务本息与融资；不代表企业收益或融资决策。
